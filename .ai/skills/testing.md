# Testing

## Objetivo
Garantir qualidade por meio de testes escritos a partir de especificações.

## Tipos de teste
- Testes unitários para funções e serviços isolados.
- Testes de integração para endpoints e fluxos de API.
- Testes end-to-end para cenários de busca e navegação.

## Abordagem
- Escrever o teste primeiro, falhar, implementar e validar.
- Usar nomenclatura clara: `should ...` ou `deve ...`.
- Documentar os critérios de aceitação nos próprios testes.
