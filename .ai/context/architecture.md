# Arquitetura

Este projeto será baseado em uma arquitetura minimalista para API, combinando:

- Backend .NET Minimal API
- Frontend Angular SPA
- Camada de documentação e especificação em `docs/`
- Desenvolvimento guiado por especificações (Spec Driven Development)

## Diretrizes
- APIs definidas por contrato e testes de integração
- Frontend dirigido por componentes e rotas claras
- Separação entre contexto de negócio e infraestrutura
