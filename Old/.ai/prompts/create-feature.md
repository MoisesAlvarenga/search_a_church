# Prompt: Criar nova feature

Descreva a feature desejada, seus critérios de aceitação e os domínios envolvidos.

Exemplo:
- Feature: Buscar igrejas por nome e localização
- Critérios:
  - Deve retornar resultados relevantes para a busca
  - Deve exibir informações de nome, endereço e horários
  - Deve funcionar com filtros de distância
