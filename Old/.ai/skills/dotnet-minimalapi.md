# .NET Minimal API

## Objetivo
Construir o backend com .NET Minimal API para fornecer endpoints REST simples e escaláveis.

## Padrões
- Usar `Program.cs` enxuto com configuração de serviços e middlewares.
- Definir contratos DTO claros e validar entrada.
- Configurar CORS, autenticação e documentação Swagger.

## Considerações
- Persistência com Entity Framework Core ou outro ORM leve.
- Paginação e filtros para endpoints de busca.
- Logs estruturados e monitoramento básico.
