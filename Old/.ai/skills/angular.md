# Angular

## Objetivo
Construir o frontend com Angular para oferecer uma experiência de busca e navegação de igrejas moderna.

## Diretrizes
- Aplicação como SPA com rotas para pesquisa, detalhes e perfil de igreja.
- Componentes modulares e reutilizáveis.
- Comunicação com API via serviços HTTP.
- Integração de testes unitários com Jasmine/Karma e testes de componente com Cypress, se desejado.
