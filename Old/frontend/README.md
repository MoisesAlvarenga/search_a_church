Placeholder para o repositório frontend do projeto.

## Objetivo
Construir o app Angular com mapa interativo, busca por perfil e visualização de igrejas em uma experiência de descoberta.

## Mapas
- Integração profunda com Google Maps para exibir marcadores de igrejas.
- Uso do Google Maps JavaScript API para renderizar o mapa e interagir com resultados.
- Uso do Google Places API ou Places Library para buscar igrejas não cadastradas via dados do mapa.
