# Search a Church

Repositório geral para regras, especificações e direção do ecossistema de descoberta de igrejas.

## Objetivo
Construir uma plataforma integrada a mapas para viajantes e pessoas procurando igrejas que tenham perfil, distância e exibição geoespacial.

## Estrutura do repositório
- `.ai/` - contexto, skills, prompts e templates para Spec Driven Development
- `docs/` - decisões arquiteturais, arquitetura e especificações de domínio
- `tests/` - orientações de testes e estratégias de validação
- `backend/` - placeholder do repositório .NET Minimal API
- `frontend/` - placeholder do repositório Angular

## Estratégia de repositórios
1. `search-a-church-rules` (atual): regras, especificações, documentação e decisões
2. `search-a-church-backend`: backend .NET Minimal API, PostgreSQL, JWT e serviços de busca
3. `search-a-church-frontend`: app Angular com integração de mapas e busca por perfil
