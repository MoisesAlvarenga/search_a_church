# API

## Design de API
- Endpoints REST simples e previsíveis.
- Uso de convenções HTTP: GET para leitura, POST para criação, PUT/PATCH para atualização.

## Contratos
- DTOs explícitos para requisição e resposta.
- Documentação com Swagger/OpenAPI.

## Funcionalidades iniciais
- Pesquisa de igrejas com filtros.
- Recuperação de detalhes de igreja e eventos.
- Autenticação para operações protegidas.
