# Camadas da Arquitetura

## Apresentação
- Frontend Angular como SPA.
- Responsável pela experiência do usuário, navegação e apresentação de resultados.

## Aplicação
- Minimal API .NET que orquestra solicitações, valida dados e aplica regras de negócio.
- Serviços e adaptadores para separar lógica de domínio de infraestrutura.

## Domínio
- Regras de negócio para busca, gerenciamento de igrejas, eventos e membros.
- Modelos de domínio e contratos de serviço.

## Infraestrutura
- Persistência de dados, serviços externos, autenticação e integração.
- Configurações de banco, logs e deploy.
