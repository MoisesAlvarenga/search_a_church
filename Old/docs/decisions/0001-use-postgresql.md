# 0001 - Usar PostgreSQL

## Decisão
Usar PostgreSQL como banco de dados relacional para o projeto.

## Motivação
- Suporte sólido a transações e consultas complexas.
- Boa integração com .NET e EF Core.
- Escalabilidade e consistência para dados de igrejas, eventos e membros.

## Consequências
- A aplicação deve incluir a configuração de conexão a PostgreSQL.
- O ambiente de desenvolvimento e produção precisa ter PostgreSQL disponível.
