# Especificações de Busca

Este diretório reúne os requisitos e critérios de aceitação para a plataforma de descoberta de igrejas.

## Domínio
- Pesquisar igrejas por nome, endereço, perfil do usuário e proximidade.
- Filtrar resultados por distância, horários, tipo de culto e relevância.
- Exibir igrejas em um mapa integrado ao app.

## Critérios Iniciais
- Deve retornar resultados relevantes ao perfil definido pelo usuário.
- Deve suportar pesquisa por localização atual, endereço ou cidade.
- Deve exibir informações essenciais e posição geográfica no mapa.
