# 0002 - Usar Clean Architecture

## Decisão
Adotar princípios de Clean Architecture para organizar o backend.

## Motivação
- Separar domínio, aplicação e infraestrutura.
- Facilitar testes, manutenção e evolução do código.
- Evitar acoplamento direto entre UI, API e persistência.

## Consequências
- Criar pastas e camadas claras no backend.
- Manter regras de negócio independentes de frameworks externos.
