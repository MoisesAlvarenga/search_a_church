# 0004 - Usar Minimal API

## Decisão
Implementar o backend usando .NET Minimal API.

## Motivação
- Código mais enxuto e rápido de configurar.
- Adequado para APIs REST simples e focadas.
- Facilita prototipagem e evolução incremental.

## Consequências
- Definir rotas e serviços diretamente em `Program.cs` ou arquivos de extensão.
- Preservar boa organização mesmo com minimalismo.
