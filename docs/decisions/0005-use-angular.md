# 0005 - Usar Angular

## Decisão
Utilizar Angular para o frontend da aplicação.

## Motivação
- Boa capacidade para SPAs e aplicações de busca.
- Padrões de componentes e serviços bem definidos.
- Facilita testes e manutenção da interface.

## Consequências
- Necessidade de criar o projeto Angular em `src/client`.
- Implementar comunicação com a API .NET via serviços HTTP.
