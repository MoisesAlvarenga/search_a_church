# Frontend

## Estrutura
- Aplicação Angular como SPA.
- Páginas para busca, resultado, detalhes e perfil de igreja.

## Comunicação
- Serviços HTTP responsáveis por consumir a API .NET.
- Tratamento de erros e estados de carregamento.

## Mapas
- Integração com Google Maps para exibir igrejas com marcadores.
- Uso de recursos do Maps para visualização geográfica e dados de localização.

## UX
- Interface responsiva e acessível.
- Exibição clara de informações de localização, horários e contato.
