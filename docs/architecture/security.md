# Segurança

## Autenticação e Autorização
- Uso de JWT para autenticação.
- Rotas públicas para pesquisa e rotas protegidas para operações administrativas.

## Validação
- Validação de entrada no backend para evitar dados inválidos ou maliciosos.
- Sanitização de parâmetros de consulta e corpo de requisição.

## Práticas
- Uso de HTTPS em ambientes de produção.
- Configuração segura de CORS.
- Logs de auditoria para eventos importantes.
