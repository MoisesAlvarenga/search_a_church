# Visão de Arquitetura

O projeto `search a church` será construído com os seguintes blocos:

- Backend: .NET Minimal API, expõe endpoints REST para busca e descoberta de igrejas por perfil, distância e localização
- Frontend: Angular SPA com mapa interativo e visualização de igrejas no app
- Documentação e especificações orientadas a comportamento em `docs/`
- Desenvolvimento iterativo baseado em critérios de aceitação e fluxo de descoberta
